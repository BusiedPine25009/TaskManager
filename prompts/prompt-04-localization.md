# ЭТАП 4. Многоязычный интерфейс TaskManager: русский, English, Қазақша + кнопка смены языка

Ты продолжаешь разработку готового приложения TaskManager (C#, .NET 10, Avalonia UI 12.1.4, FluentTheme, шрифт Inter, macOS).
Приложение уже работает. **Не переписывай его с нуля, не ломай существующие функции и слои UI / логика / данные.**

## 1. Цель

1. Весь интерфейс должен быть на трёх языках: русский (ru), английский (en), казахский (kk).
2. В шапке главного окна появляется кнопка выбора языка. Язык переключается **сразу, без перезапуска**.
3. Выбранный язык сохраняется между запусками.

## 2. Готовые файлы переводов (уже лежат в проекте, не переделывай)

- `Assets/Localization/ru.json`
- `Assets/Localization/en.json`
- `Assets/Localization/kk.json`

В них по 128 ключей, во всех трёх файлах ключи одинаковые. Это плоские словари «ключ → строка». Правила:
- Ключи не переименовывать. Если нужен новый текст, добавь ключ **во все три файла** одновременно.
- `{0}`, `{1}` — подставляемые значения для `string.Format`. Менять и убирать нельзя.
- Ключи `time.day`, `time.hour`, `time.minute` содержат формы множественного числа через `|`:
  - ru: три формы (`1` / `2–4` / `5+`), правило уже есть в `TaskCardViewModel.Plural`;
  - en: две формы (`1` → первая, всё остальное → вторая);
  - kk: одна форма (после числа слово не изменяется).
- Подписи, написанные заглавными буквами (например `stats.total`), в файлах уже в верхнем регистре, ничего дополнительно не переводи в верхний регистр.
- Текст, который вводит пользователь (названия, описания, проекты задач), **не переводится**.
- `Assets/**` уже подключено в `.csproj` как `AvaloniaResource`, JSON-файлы будут встроены автоматически. Проверь это.

## 3. Архитектура (держи простой, это курсовая: код придётся объяснять)

**3.1. Класс локализации** (`Services/LocalizationService.cs` или `Localization/Loc.cs`):
- Singleton `Loc.Instance`, реализует `INotifyPropertyChanged`.
- Индексатор `this[string key]` возвращает строку текущего языка. При смене языка вызывай `PropertyChanged` для `"Item[]"`, чтобы обновились все привязки в XAML.
- Статические методы для C#-кода: `Loc.T(string key)`, `Loc.T(string key, params object[] args)` (через `string.Format`), `Loc.Plural(string key, int n)` (выбор формы по правилам текущего языка).
- Событие `LanguageChanged`.
- Загрузка JSON из ресурсов Avalonia (`avares://TaskManager/Assets/Localization/{lang}.json`) через `System.Text.Json`.
- Порядок поиска строки: текущий язык → русский → сам ключ. **Приложение не должно падать из-за отсутствующего ключа.**
- Модели и сервисы тоже могут вызывать `Loc.T(...)` для сообщений об ошибках. Отдельный слой для этого не нужен.

**3.2. Сохранение выбора** — `Services/LanguagePreferenceService.cs` по образцу существующего `ThemePreferenceService`: файл `language.txt` в той же папке (`LocalApplicationData/TaskManager`). Значения: `ru`, `en`, `kk`.
Язык по умолчанию: если системный язык ru, en или kk — он, иначе `ru`. Если файл повреждён или содержит неизвестное значение, используй значение по умолчанию.

**3.3. Культура.** При смене языка устанавливай `CultureInfo.CurrentCulture`, `CultureInfo.CurrentUICulture`, `CultureInfo.DefaultThreadCurrentCulture` и `DefaultThreadCurrentUICulture` в `ru-RU`, `en-US`, `kk-KZ`, чтобы названия месяцев в календаре (DatePicker) и время в TimePicker соответствовали языку. Формат даты и времени в интерфейсе оставь прежним (`dd.MM.yyyy, HH:mm`) для всех языков.

## 4. Кнопка выбора языка

- Место: шапка главного окна, **слева от кнопки темы** (порядок: язык, тема, корзина, «Добавить задачу»).
- Стиль: класс `secondary`, как у кнопки темы. Внутри векторная иконка глобуса и название текущего языка на этом же языке (`lang.name.*`: «Русский», «English», «Қазақша»).
- По нажатию открывается небольшое меню (`MenuFlyout`) из трёх пунктов: Русский, English, Қазақша. Текущий язык отмечен галочкой. Подсказка кнопки: ключ `lang.tooltip`.
- Иконку рисуй так же, как иконки темы: `Viewbox` + `Canvas` 24×24 + `Path` с классом `icon`. Данные для глобуса (проверены, выглядят правильно):

```
M22,12 A10,10 0 1 1 2,12 A10,10 0 1 1 22,12 Z M2,12 H22 M12,2 A15.3,15.3 0 0 1 16,12 A15.3,15.3 0 0 1 12,22 A15.3,15.3 0 0 1 8,12 A15.3,15.3 0 0 1 12,2 Z
```

- Если с `MenuFlyout` возникнут трудности, допустимый запасной вариант: кнопка переключает языки по кругу ru → en → kk, а подпись и подсказка показывают текущий.

## 5. Что заменить на локализованные строки

Найди **все** жёстко прописанные русские тексты (кроме комментариев) в XAML и C#.

- **XAML:** привязывай тексты к индексатору, например `Text="{Binding [main.addTask], Source={x:Static loc:Loc.Instance}}"`. В Avalonia 12 по умолчанию включены compiled bindings: если привязка к индексатору с `Source` не компилируется, используй `x:CompileBindings="False"` на этом элементе или markup-extension. Выбери решение, которое проще всего, и **используй его везде одинаково**.
- **C#:** заменяй на `Loc.T("ключ")`.
- Файлы (проверь каждый): `MainWindow.axaml(.cs)`, `App.axaml`, `Program.cs`, `Dialogs/*` (`ConfirmationDialog`, `MessageDialog`, `RecoveryDialog`, `RecycleBinWindow`, `TaskEditWindow`), `ViewModels/TaskCardViewModel.cs`, `ViewModels/DeletedTaskViewModel.cs`, `Models/*`, `Services/*`.
- Заголовки окон (`Title=`) и значения по умолчанию в конструкторах диалогов тоже переводи.
- `EnumExtensions.ToRussian(...)` замени на метод с нейтральным названием (например `ToDisplayName`), который берёт тексты из ключей `enum.priority.*` и `enum.state.*`. Обнови все места использования.
- `GetTypeName()` и `GetDetails()` в моделях (демонстрация полиморфизма) оставь, но тексты бери из ключей `enum.type.*`, `card.project`, `card.repeatEvery` и т. д.
- `TaskCardViewModel.FormatRemaining` и `Plural`: используй `Loc.Plural` и ключи `card.timeLeft`, `card.overdueBy`, `time.*`.
- Фильтры в выпадающих списках (`StateFilter`, `PriorityFilter`) пересоздавай при смене языка, **сохранив выбранный пункт**.

## 6. Обновление при смене языка

- В главном окне подпишись на `Loc.LanguageChanged`: вызови `Refresh()` и обнови все вычисляемые свойства (тексты кнопки корзины, подсказки темы, пустые состояния, фильтры, карточки).
- Диалоги модальные, во время их показа язык сменить нельзя: им достаточно брать язык при создании.
- Тема и язык независимы, смена одного не должна сбрасывать другое.

## 7. Дизайн и вёрстка

Тексты на английском и казахском длиннее или короче русских. Проверь и при необходимости поправь вёрстку:
- ничего не обрезается и не перекрывается (кнопки, фильтры, бейджи, карточки статистики, шапка);
- для `ComboBox`, кнопок и подписей используй `MinWidth` и автоматическую ширину вместо жёстких значений;
- шапка на узком окне не ломается;
- казахские буквы (ә, ғ, қ, ң, ө, ү, ұ, һ, і) отображаются шрифтом Inter (поддержка проверена).

## 8. Чего не делать

- Не менять формат хранения данных (JSON задач и корзины остаются независимыми от языка; перечисления хранятся как раньше).
- Не менять путь хранения файлов, иконку приложения, скрипт `build-macos-app.sh`.
- Не добавлять платные и тяжёлые библиотеки. Файлы `.resx` и пакеты локализации не нужны.
- Не переводить пользовательские данные.

## 9. Код

К каждому новому классу, методу и сложному фрагменту напиши подробный комментарий **на русском**. Код чистый и читаемый, без лишнего вывода.

## 10. Проверка перед сдачей

1. `dotnet build` без ошибок и предупреждений.
2. В трёх файлах JSON одинаковый набор ключей (напиши короткий скрипт или тест для проверки). Ни один ключ из кода не отсутствует в файлах.
3. Переключение ru → en → kk → ru работает без перезапуска, главное окно, форма задачи, корзина и диалоги везде на выбранном языке.
4. Язык сохраняется после перезапуска, и тема при этом не сбрасывается.
5. Нет русских строк, оставшихся в интерфейсе при английском и казахском (кроме пользовательских данных).
6. Склонения: `1 день / 2 дня / 5 дней`, `1 day / 2 days`, `1 күн / 2 күн / 5 күн`.
7. После готовности перечисли изменённые файлы и расскажи, как проверить работу.
